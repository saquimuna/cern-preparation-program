# Programa de preparación CERN - ESPE

## Objetivo Personal
Me gustaría obtener nuevos aprendizajes técnicos y científicos que me permitan crecer académicamente. También, pretendo ir cumpliendo el curso apuntando a ser seleccionada dentro del programa del CERN, me gusta mucho el hecho de combinar los conocimientos de Desarrollo de Software con Física.

## Tecnologías y Áreas que Deseo Fortalecer
- **Bases de datos:** Comprensión y manejo de estructuras de datos.
- **Herramientas prácticas:** Uso de herramientas útiles para el entorno laboral y de desarrollo.
- **Programación aplicada:** Aplicaciones prácticas de los lenguajes de programación.
- **Software + Física:** Integración de conceptos de desarrollo para resolver problemas científicos.
